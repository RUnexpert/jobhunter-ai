# Реализованные возможности и ограничения

| Область               | Реализовано                                                                                                                   | Граница                                                                                                                        |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Авторизация JobHunter | Закрытая регистрация по коду, bcrypt, HttpOnly-сессии, Origin-проверка, rate limit                                            | Восстановление пароля и MFA не входят в эту версию                                                                             |
| hh.ru                 | OAuth PKCE/state, /me, одноразовый refresh под блокировкой, шифрование, отключение                                            | Нужна регистрация приложения и доступ hh.ru                                                                                    |
| Резюме / кандидат     | Несколько резюме, редактирование, подтверждённые факты, навыки с опытом, английский, зарплата, переезд, командировки          | Импорт собственных резюме не подтверждён public OpenAPI; ручной ввод                                                           |
| Поиск                 | Профили, импорт URL, фильтры, списки работодателей, выбранные резюме, веса, лимиты, расписание, ручной запуск                 | До 30 профилей, до 2000 результатов на проход; действуют лимиты hh.ru                                                          |
| AI                    | Четыре назначения, OpenAI-compatible / Ollama, JSON/Zod, выбор резюме, объяснение, уверенность, стоимость и бюджет            | Нужна подходящая модель; денежные цены настраивает пользователь; неизвестная стоимость резервируется                           |
| Письма                | Предпросмотр, редактирование, регенерация, политики NEVER/ALWAYS/AI                                                           | Фактические фразы берутся дословно из базы; для английского нужны факты на английском                                          |
| Отклики               | Подготовка, Dry Run, ручное подтверждение, kanban/таблица, уникальность, rolling 24h limits                                   | В текущей public OpenAPI нет подтверждённой отправки соискателем; APPLIED = USER_REPORTED                                      |
| Вопросы / тестовые    | Классификация, черновики фактических/технических ответов, задания/личные тесты человеку, сроки и материалы                    | Вопрос из анкеты вставляется вручную; исполнения кода и отправки теста нет                                                     |
| Мониторинг            | Новые чаты, пагинация и курсоры, классификация сообщений, приоритетные задачи                                                 | Доступ зависит от hh.ru. Статусы откликов отмечаются вручную; из текста сообщения не выдумывается подтверждение API            |
| Уведомления           | SMTP/TLS, адаптивный HTML + text, дедупликация, события и дайджест                                                            | Без SMTP остаются внутри приложения; Telegram не реализован (опционален в ТЗ)                                                  |
| Управление            | Start / pause / stop, часы, лимиты, blacklist вакансий и компаний, отключение профиля                                         | Уже начатый HTTP-запрос может завершиться после остановки                                                                      |
| Данные / аналитика    | KPI, 7/30/90 дней, воронка, сравнение профилей/резюме/писем, AI-рекомендации, CSV, обратная связь                             | Источник этапов — ручные отметки. До 10 000 записей на расчёт dashboard; CSV до 50 000. Выводы по малой выборке не формируются |
| Надёжность            | PostgreSQL, 7 BullMQ очередей, bounded retries, лимиты concurrency/backlog, восстановление незавершённых записей, SSE, журнал | SMTP не гарантирует exactly-once; повтор при неопределённом результате может дать дубль письма                                 |
| Развёртывание         | Docker Compose, миграции, .env.example, инструкция VPS                                                                        | Нужны HTTPS, ключи и операционные резервные копии владельца                                                                    |

Система не обходит CAPTCHA и антибот-механизмы, не использует недокументированную отправку, не отправляет сообщения работодателям и не исполняет код заданий. Сведения из вакансий и сообщений считаются недоверенными данными, а не командами.
