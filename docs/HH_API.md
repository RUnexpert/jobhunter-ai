# Возможности hh.ru

Проверка 27 октября 2026: [официальная спецификация](https://api.hh.ru/openapi/specification/public), [ReDoc](https://api.hh.ru/openapi/redoc), [официальный репозиторий](https://github.com/hhru/api). Машинный результат и SHA-256 загруженного файла: `hh-api-audit.json`.

Старые Markdown-страницы ссылаются на операции соискателя, которых нет в скачанной public OpenAPI. Отсутствие в спецификации не доказывает отсутствие приватной возможности у hh.ru, но недостаточно для безопасной реализации. Приложение использует только подтверждённые методы. Перед подключением реальных аккаунтов разработчик должен зарегистрировать приложение на dev.hh.ru и подтвердить применимые условия использования.

## Принцип отказа по умолчанию

Автоматический режим автоматизирует поиск, оценку и подготовку. Он не превращает неподдерживаемую отправку в работающую функцию. Никакая настройка не включает скрытый POST. Переход по ссылке не означает успешный отклик. Только пользовательская отметка создаёт APPLIED с USER_REPORTED. Отслеживание просмотров, приглашений и офферов требует ручной отметки, пока не подтверждён официальный механизм для соискателя.

Нет CAPTCHA solver, антибот-обходов, cookie scraping или браузерного отправителя. Тесты технических знаний всегда остаются черновиками для пользователя. Психологические тесты, видео, задания с личным выполнением и неизвестные анкеты передаются человеку.

## Лимиты

Проверка профиля — не чаще 15 минут; умолчание 60 минут. HTTP timeout 20 секунд; максимум 3 попытки GET с exponential backoff. Длинный Retry-After прекращает текущую обработку. OAuth POST не повторяется автоматически. Отдельные BullMQ-задачи имеют 3 ограниченные попытки. Фактические лимиты hh.ru не фиксируются вымышленной константой: 429 обрабатывается как ограничение платформы.
